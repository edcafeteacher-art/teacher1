# teacher1

Репозиторий содержит субагента Claude Code `teacher-assistant` и навык `worksheet-builder`. Вместе они собирают рабочие листы по английскому для специальных целей (ESP) для студентов СПО по утверждённой доктрине преподавателя. Это шаблон Hobbies, алгоритм из 9 частей и режимы F1, F2, B1, B2.

## Как пользоваться

Откройте репозиторий в Claude Code и напишите, например:

> Попроси teacher-assistant сделать рабочий лист для 1 курса банковского дела, уровень A2, по этому тексту.

Агент сначала задаст уточняющие вопросы (специальность, курс, уровень, текст, глоссарий, ключ ответов, Case Challenge) и только после ответа соберёт `.docx` в каталог `materials/`.

## Файлы

- `.claude/agents/teacher-assistant.md` описывает агента и порядок его работы.
- `.claude/skills/worksheet-builder/` содержит доктрину. Здесь `SKILL.md` с алгоритмом, `references/` с уровнями, специальностями и проверкой фактов, `assets/` с шаблоном Word и шаблоном дашборда, `scripts/` с движком сборки и проверкой, `examples/` с пятью принятыми листами.
- `materials/` предназначен для готовых листов.

## Что нужно для сборки

python3 с `lxml`, а для проверки страниц ещё LibreOffice (`soffice`), poppler (`pdftoppm`) и Pillow.

Листы, собранные агентом, требуют проверки преподавателем перед уроком, особенно ключи ответов и факты.

## Инструмент методического аудита

`tools/course-audit.html` открывается в браузере без установки. Он ведёт эксперта по мастер-промпту независимого аудита курса. В нём есть паспорт курса, реестр материалов с загрузкой файлов DOCX, PDF, TXT и MD (текст извлекается в браузере), восемь блоков с контрольными вопросами и шкалой 0–5 или Н/Д, анализатор формулировок результатов, конструктор заданий, матрица согласованности, таблица проблем, план улучшения и сборка отчёта в Markdown. Работа сохраняется в браузере, перенос между устройствами выполняется через резервную копию в формате JSON.
