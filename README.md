# teacher1

Репозиторий содержит субагента Claude Code `teacher-assistant`, который помогает учителю готовить планы уроков, задания, проверочные работы, ключи ответов и критерии оценивания на русском и английском языках.

## Как пользоваться

Откройте репозиторий в Claude Code и сформулируйте запрос, например так:

> Попроси teacher-assistant подготовить самостоятельную работу по теме «Линейная функция» для 7 класса в двух вариантах с ключом ответов.

Агент уточнит недостающие параметры (предмет, класс, тему, тип материала), а готовые файлы по просьбе сохранит в каталог `materials/`.

## Файлы

- `.claude/agents/teacher-assistant.md` содержит описание и системный промпт агента.
- `materials/` предназначен для сохранённых материалов.

Материалы, подготовленные агентом, требуют проверки учителем перед использованием на уроке.
